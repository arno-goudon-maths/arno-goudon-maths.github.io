x, x², x³ et √x

Faites glisser le point rouge sur l'axe des abscisses : les quatre images se rangent sur la verticale. Regardez ce qui se passe quand x franchit 1.

Pour aller plus loin

Pour tout réel x de ]0 ; 1[ : x³ < x² < x < √x. Pour tout réel x > 1 : √x < x < x² < x³. En 0 et en 1, les quatre nombres sont égaux.

Par exemple, pour comparer x et x² : x² − x = x(x − 1), dont on étudie le signe avec un tableau de signes.
