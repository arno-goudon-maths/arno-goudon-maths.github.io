Où vit ce nombre ?

Choisissez un nombre : il se pose dans le plus petit ensemble qui le contient. Zoomez ensuite sur la droite graduée : un nombre décimal finit toujours par tomber pile sur une graduation.

Pour aller plus loin

ℕ : les entiers naturels 0 ; 1 ; 2 ; … — ℤ : les entiers relatifs … ; −1 ; 0 ; 1 ; … — 𝔻 : les nombres de la forme a/10n avec a ∈ ℤ et n ∈ ℕ, c'est-à-dire avec un nombre fini de décimales — ℚ : les nombres de la forme p/q avec p ∈ ℤ et q ∈ ℕ* — ℝ : tous les nombres de la droite graduée.

On a ℕ ⊂ ℤ ⊂ 𝔻 ⊂ ℚ ⊂ ℝ. L'écriture décimale d'un rationnel finit toujours par se répéter ; celle de √2 ou de π ne se répète jamais.
