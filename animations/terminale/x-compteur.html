X, le compteur de succès

Une roue de loterie tourne cinq fois : c'est un schéma de Bernoulli. X compte les succès. Relancez plusieurs fois et regardez si X donne toujours le même nombre.

Aucune répétition pour l'instant.

Pour aller plus loin

Sur une seule répétition, X peut prendre les valeurs 0, 1, 2, 3, 4 ou 5. Sa loi est la loi binomiale 𝓑(5 ; 0,4) : P(X = k) = (k parmi 5) × 0,4k × 0,65 − k.
